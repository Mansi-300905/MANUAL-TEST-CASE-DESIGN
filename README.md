# MANUAL-TEST-CASE-DESIGN
Intern ID: CITS4361 Name: Mansi Ramesh Aeer

Domain: Software Testing

Project Name: Manual Test Case Design for www.aramya.in

Description: Designed comprehensive manual test cases for the www.aramya.in website to verify its functionality, usability, navigation, and overall performance. The project involved analyzing software requirements, identifying test scenarios, creating positive and negative test cases, and ensuring that all major features of the website were covered through systematic manual testing.

Technology/Tools: Manual Testing, Microsoft Excel, Microsoft Word, Google Chrome, Microsoft Edge, Bug Tracking Tools (Excel/JIRA), MS Office.

Key Feature: Developed detailed manual test cases with test case IDs, preconditions, test steps, test data, expected results, and actual results. Covered functional, UI, navigation, form validation, compatibility, and usability testing to ensure complete test coverage and improve the quality and reliability of the website.
